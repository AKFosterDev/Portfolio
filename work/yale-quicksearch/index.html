Case study · Yale University Library

Redesigning Quicksearch for a new library system

Yale's library discovery platform needed new holdings and request pages when the library moved from Voyager to Alma and Primo VE. I worked on it from first mockups through production over more than 18 months.

Role
Software engineer, design and front end
Timeline
March 2023 – June 2026
Tools
Figma, Rails, Bootstrap 5, SCSS, RSpec
Team
Notch8 with Yale Library staff

The problem

Patrons find and request items through Quicksearch. The move to Alma and Primo VE changed the data behind every holdings record, so the pages that show where an item is and how to request it had to be redesigned without disrupting people who use them every day.

What I did

  • Created Figma mockups and design options, then built the approved designs
  • Audited every page from 320 to 1680 pixels and fixed layout problems before they were reported
  • Improved WCAG 2 Level AA conformance, including screen-reader-only text patterns
  • Migrated Bootstrap 4 to 5, moved the stylesheets from Sass to SCSS and helped convert the templates from HAML to ERB
  • Wrote the team's ticket, pull request and breakpoint testing templates
